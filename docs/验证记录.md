## 已知能力边界

Spine 当前仅支持 4.2 导出；Lottie 不执行表达式且不自动拉取外部字体或图片；SVGA 和视频音频不播放；VAP / YYEVA 时间定位近似；spritesheet 只支持规则无间距网格。当前验证通过不等于所有动画版本、AE 特性、设备编码或 App 表现都兼容。
